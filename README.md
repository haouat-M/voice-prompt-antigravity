# Voice Prompt for Antigravity

Fast and lightweight voice typing extension for Antigravity IDE.

## Features

- Speaks directly into the Antigravity chat prompt.
- High-accuracy Arabic speech recognition with automatic conversion of technical programming terms into English.
- Minimal status bar icon: clean microphone symbol without cluttered text labels.
- Keyboard shortcut: press `Ctrl+Alt+A` to start or stop recording.
- Adjustable silence pause threshold for comfortable speech.

## Usage

1. Click the microphone icon in the bottom status bar, or press `Ctrl+Alt+A`.
2. Speak your instructions.
3. Pause naturally or press the shortcut again to finish.
4. Your words appear directly in the active chat prompt.
